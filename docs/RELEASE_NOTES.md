# v0.1.2 · 控制台自动登录与部署后配置同步

- 运行管理和桥接部署完成后的步骤面板显示 QQ Bridge 控制台访问令牌，支持刷新和原生剪贴板复制。
- 通过助手启动、重启或打开桥接控制台时自动带入当前令牌，保留上游认证；支持自定义控制台端口及令牌轮换。
- 部署最后自动扫描、备份并应用实际安装路径、已验证的 Harness API、唯一匹配的 OneBot HTTP/WS 地址和独立令牌；保留已有管理员、白名单、模型、角色及其他配置。
- desktop 插件安装完成后自动重新启动 Harness；首次登录未完成时明确等待用户，确认 API 可用后再继续同步。
- 启动桥接前刷新 Harness 动态端口；修正 Harness preset RPC 的 `args` 包装和桥接控制台鉴权头，并检查 `dshReady`，避免进程存在却误报链路正常。
- 多个网关配置无法唯一匹配时保留原连接并提示选择；同步后自动刷新表单，助手管理的桥接会重启应用变更。
- 控制台令牌通过独立 IPC 读取，不进入通用快照、助手活动日志或诊断导出。

# v0.1.1 · 修复 SnowLuma 后台初始密码展示

- 修复 SnowLuma 安装后后台初始密码只写入本机日志、无法从部署界面获取的问题。
- 部署等待页面自动显示登录账号和初始密码，支持复制密码、打开后台；运行管理中也可查看和刷新。
- 读取初始密码时核验当前安装的密码哈希；重启后更新为新密码，后台改密后停止显示旧密码。
- 初始密码不写入助手活动日志、配置或诊断导出；复制使用 Electron 原生剪贴板接口。

下载 `QQDshDeployer-0.1.1-x64-Setup.exe` 安装，或使用 `QQDshDeployer-0.1.1-x64-Portable.exe` 便携版。安装版旧用户可通过应用内更新升级。

已通过 34 项常规自动测试、21 项安装后 EXE 界面检查、5 项安装 / 卸载 / 便携发行检查及 2 项真实更新下载校验场景。SnowLuma 凭据界面使用与上游 2.1.1 格式一致的隔离测试数据验证；真实首次设置和 QQ 登录仍需用户参与。
